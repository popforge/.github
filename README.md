# popforge/.github

Fichiers par défaut des dépôts du compte `popforge`. GitHub les applique à tout dépôt qui n'a pas ses propres fichiers du même type.

| Fichier | Rôle |
|---|---|
| `.github/ISSUE_TEMPLATE/1-fonctionnalite.yml` | Gabarit **Fonctionnalité** (étiquette `enhancement`) |
| `.github/ISSUE_TEMPLATE/2-bogue.yml` | Gabarit **Bogue** (étiquette `bug`) |
| `.github/ISSUE_TEMPLATE/3-spec.yml` | Gabarit **Spec** (étiquette `spec`) |

Les conventions de travail sont dans le dépôt privé `popforge/docs`.
